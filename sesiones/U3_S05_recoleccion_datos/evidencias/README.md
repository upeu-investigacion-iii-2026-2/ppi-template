# Evidencias — U3 Sesión 5

Esta carpeta contiene los archivos complementarios de la recolección de datos.

## Evidencias sugeridas

- matriz indicador–técnica–instrumento–fuente;
- constancias de validación o juicio de expertos;
- resultados y análisis de confiabilidad;
- registro y resultados de la prueba piloto;
- protocolo y calendario de recolección;
- diccionario de datos;
- scripts de limpieza y control de calidad;
- formatos de consentimiento (sin datos personales);
- muestras anonimizadas de los datos.

## Organización recomendada

```text
evidencias/
├── validacion/
├── piloto/
├── protocolo/
├── diccionario/
└── calidad/
```

No se deben subir datos personales identificables ni datos cuya licencia
prohíba su redistribución. En esos casos, registrar la referencia, el acceso y
las instrucciones para obtenerlos.
